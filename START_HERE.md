# 🎮 POKÉMON EXPLORER - START HERE!

Welcome to your brand new Pokémon Explorer website! 🚀

## ⚡ Quick Start (2 minutes)

### Windows Users:
```cmd
setup.bat
npm start
```
Then open: **http://localhost:5000**

### Mac/Linux Users:
```bash
chmod +x setup.sh
./setup.sh
npm start
```
Then open: **http://localhost:5000**

## ❓ Quick Troubleshooting

**"Address already in use" error?**
```bash
PORT=3000 npm start
```

**Can't find npm?**
- Install Node.js from https://nodejs.org/

**Images not showing?**
- Check your internet connection
- Reload the page

**Search not working?**
- Make sure server is running
- Check browser console (F12)
