## 🐛 Troubleshooting Reference

**Port in use?** → `PORT=3000 npm start`
**npm missing?** → Install Node.js from nodejs.org
**Images not showing?** → Check internet connection
**Search not working?** → Verify server is running
**Favorites lost?** → Clear browser cache, try incognito mode
